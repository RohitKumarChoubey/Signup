🚀 SignUp System

A simple SignUp & Registration System built with a frontend hosted on AWS S3 and a backend deployed using AWS Elastic Beanstalk. This project allows users to register and store their information securely.

📌 Project Author

Rohit Choubey
B.Tech Computer Science Engineering (2023–2027)

📖 Project Overview

The SignUp System is a full-stack web application that provides:

User registration

Backend REST APIs

Cloud-hosted frontend

Database integration using MongoDB Atlas

This project demonstrates cloud deployment and full-stack development using AWS and MongoDB.

Maven

Git

MongoDB Atlas Account

Internet Connection
MongoDB Atlas Setup
Step 1: Create Account

Go to: https://www.mongodb.com/cloud/atlas

Sign up / Login

Step 2: Create Cluster

Click Create Cluster

Choose Free Tier (M0)

Select Region (Nearest to you)

Create cluster

Step 3: Create Database User

Go to Database Access

Add New User

Set Username & Password

Give Read and Write access

Step 4: Allow Network Access

Go to Network Access

Click Add IP Address

Select Allow Access From Anywhere (0.0.0.0/0)

Step 5: Get Connection String

Click Connect

Choose Connect your application

Copy connection URI
